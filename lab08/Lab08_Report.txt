1. Disk Scheduling

FCFS อ่านคำขอตามลำดับที่เข้ามา ทำให้หัวอ่านกระโดดไปมาระหว่างตำแหน่งไกล ๆ จึงเคลื่อนที่รวม 640 cylinders ส่วน SCAN เรียงคำขอแล้วเคลื่อนที่ขึ้นไปทางเดียวจนถึงปลาย Disk ก่อนย้อนกลับ ทำให้ระยะทางรวมเหลือ 331 cylinders

2. I/O Bound

I/O Bound หมายถึงงานต้องรอการอ่านหรือเขียนข้อมูลเป็นหลัก CPU จึงไม่ได้ทำงานเต็ม 100% แต่มีช่วงว่างรอ Disk หรืออุปกรณ์ I/O เมื่อข้อมูลมาถึงจึงกลับมาประมวลผลต่อ

3. การประยุกต์กับ Dataset

ไฟล์ .jpg จำนวนมากทำให้ OS ต้องเปิดไฟล์ ตรวจ Metadata ตรวจสิทธิ์ และปิดไฟล์ซ้ำเป็นล้านครั้ง การเข้าถึงจึงมี Overhead สูงและ GPU อาจว่างรอข้อมูล หากรวมไฟล์เป็นรูปแบบต่อเนื่อง เช่น TFRecord, WebDataset หรือ HDF5 ระบบจะอ่านข้อมูลเป็นลำดับได้ง่ายกว่าและส่งข้อมูลให้ GPU ได้ต่อเนื่องขึ้น

4. สรุปและการประยุกต์ใช้

Random Access มีคอขวดจากการกระโดดไปยังตำแหน่งต่าง ๆ และการจัดการไฟล์จำนวนมาก ส่วน Sequential Access อ่านข้อมูลต่อเนื่องจึงลดงานของ OS ได้มากกว่า ใน Data Pipeline ขนาดใหญ่ ถ้า I/O ช้า GPU จะว่างงาน แม้ตัว GPU จะมีความสามารถเหลืออยู่ก็ตาม
